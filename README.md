# SPOCK

### Smart Manufacturing Operations & Predictive Control

SPOCK is a manufacturing management system for mechanical-parts companies. It connects **order tracking, inventory management, demand forecasting, production, and fulfillment** in one platform.

## Core Features

* **Order Management** — Create and track customer orders.
* **Inventory Management** — Monitor raw materials, WIP, and finished goods.
* **Demand Forecasting** — Predict future product demand using historical data.
* **Production Planning** — Identify production requirements based on demand and inventory.
* **Procurement Recommendations** — Determine what to purchase, how much, and when.
* **Fulfillment Tracking** — Monitor order fulfillment and delivery status.
* **Dashboard** — View inventory, orders, forecasts, alerts, and recommendations.
